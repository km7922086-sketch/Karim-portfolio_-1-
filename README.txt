KARIM MOHAMMAD ABDELHADY — PORTFOLIO

FILES
- index.html: website structure and content
- style.css: colors, layout, responsive design, animations
- script.js: live clock and navigation behavior
- assets/Karim-CV.pdf: CV used by the Download CV button
- assets/images/: portfolio photos and project screenshots

OPEN IN VS CODE
1. Extract this ZIP file.
2. Open VS Code.
3. Choose File > Open Folder.
4. Select the MyPortfolio folder (the folder that contains index.html).
5. Open index.html. For a live preview, install the Live Server extension, right-click index.html, and choose Open with Live Server.

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and open your portfolio repository.
2. Upload the CONTENTS of the MyPortfolio folder, not the ZIP itself. Keep index.html in the repository root, and keep style.css, script.js, and the assets folder beside it.
3. Upload the entire assets folder with its subfolders intact. The profile and project images must remain in assets/images/.
3. Commit the changes.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. Wait for the Pages deployment to finish. The site URL is usually https://YOUR-USERNAME.github.io/REPOSITORY-NAME/ .

NOTES
- Keep the relative file paths as they are.
- The Download CV button points to assets/Karim-CV.pdf.
- Check all contact links and the site on both mobile and desktop before sharing.
